# QuantumStack Source Code

This directory contains the core implementation of the QuantumStack platform.

## Directory Structure

- **`openai/`**: Core integration with OpenAI's GPT-4o for community analysis and event planning.
- **`api_controllers/`**: Request handlers for the Backend API.
- **`frontend/`**: The web platform's composition (HTML, JS, CSS).
- **`services/`**: Business logic and external service integrations (Firebase, etc.).
- **`config/`**: Environment configuration and server settings.
- **`routes/`**: API endpoint definitions.
- **`middleware/`**: Express middleware (validation, error handling, logging).
- **`utils/`**: Shared utility functions and global logger.
- **`index.ts`**: Main entry point for the backend server.
